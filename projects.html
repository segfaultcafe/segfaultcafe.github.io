01 / language active development

Predictable native software

Flecha

Flecha is my attempt to make systems programming explicit without making every line feel hostile. It is a statically typed language and LLVM-based toolchain built around predictable execution, visible ownership, checked references and slices, strong diagnostics, and native code.

Beyond the syntax, it is becoming a complete working environment: compiler, standard library, tests, editor support, and Longbow for projects and packages. It is early-stage, but designed in public and exercised by real programs.

02 / audio v0.8

Music without leaving the terminal

Termify

Termify turns the terminal into a focused music player rather than a thin wrapper around a browser. Built in modern C++ with FFmpeg and native audio backends, it can search, play online or local audio, and keep history, playlists, likes, queues, and a bounded cache.

The interface stays compact and keyboard-friendly without being austere: there is a live waveform, clickable controls, precise seeking, mouse support, and a self-contained downloader. No subscription, no ads, and no separate Python or yt-dlp installation.

03 / engine active development

A 2D engine that starts with 2D

Flatearth

Flatearth is a C++23 game engine built from the ground up for 2D work instead of treating it as a simplified 3D mode. Its Vulkan renderer, ECS, scene and asset systems, physics, animation, audio, particles, and TMX tilemaps meet in a small playable testbed.

It is also a place to explore explicit engine architecture: plain entity IDs, typed sparse sets, ordered systems, tagged allocation, and separate game and UI render passes. The goal is a small foundation whose moving parts stay visible.

  • Vulkan
